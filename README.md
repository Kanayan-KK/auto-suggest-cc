この拡張機能は、コミット対象のファイルから種別とスコープを提案し、確定した種別に合う絵文字を初期選択します（スコープの自動提案は
`conventionalCommits.defaultScopeMode` を `disabled` にすると無効になります）。

## オリジナル版との違い

次の表は、フォーク元の
[Conventional Commits](https://github.com/vivaxy/vscode-conventional-commits/tree/769bfdbcef82f1604373b29bde4335b892cac835)
と Auto Suggest CC のコミット作成画面を比較したものです。

| 項目     | オリジナル版                                                   | Auto Suggest CC                                                                                                                                                            |
| -------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 種別     | 候補の先頭を初期選択します。                                   | 対象ファイルがすべて同じ分類に当てはまるとき、`docs`、`test`、`ci` のいずれかを提案します。分類できない場合はユーザーが種別を選びます。                                    |
| スコープ | 「なし」が初期値で、ユーザーが登録済みの候補などから選びます。 | ファイルの直接の親ディレクトリ名を提案します。ルート直下では拡張子を除いたファイル名を使います。全ファイルの値が一致し、プロジェクトの検証ルールに合う場合だけ提案します。 |
| 絵文字   | 「なし」が初期値で、ユーザーが一覧から選びます。               | 確定した種別に合う絵文字を11種別から提案します。例えば `fix` は 🐛、`perf` は ⚡️ です。種別を選び直すと自動候補が変わり、手動で選んだ絵文字や「なし」は保持されます。      |
| 件名     | 空欄を許可するかはプロジェクトの検証ルールに従います。         | 絵文字を選んでいても、件名が空欄または空白だけなら入力を求めます。                                                                                                         |

例えば `docs/setup.md` と `docs/usage.md` をステージすると、Auto Suggest
CC は種別 `docs`、スコープ
`docs`、絵文字 📝 を初期選択します。既定の絵文字表記で候補をそのまま確定し、件名に「導入手順を更新」と入力すると、`docs(docs): :memo: 導入手順を更新`
になります。
